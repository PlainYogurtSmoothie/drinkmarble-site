스트리머 가이드

방송에서 주루마블을 진행하는 순서와 채팅 명령, 후원 규칙 설정을 정리했습니다. 서비스 공개 전 안내라 세부 화면은 바뀔 수 있습니다.

1. 준비

로그인
치지직 또는 씨미 계정으로 로그인하면 관리 페이지와 오버레이 주소가 생깁니다. SOOP은 관리 페이지에서 채팅 연결 버튼을 누릅니다.
OBS에 오버레이 추가
브라우저 소스 → URL에 오버레이 주소 붙이기 → 크기 1280×760 권장. 테마는 주소 뒤에 ?theme=neon 처럼 붙입니다.
판과 주사위 고르기
관리 페이지에서 프리셋을 고르거나 보드를 편집합니다. "보드만 적용"을 쓰면 규칙·주사위는 그대로 두고 판만 바뀝니다.

2. 진행

시청자가 !참가로 들어오고, 첫 굴림이 곧 시작입니다. 순서제에서는 자기 차례에만 !주사위가 먹고, 자유 모드에서는 각자 쿨다운마다 굴릴 수 있습니다. 관리 페이지의 큰 버튼으로 스트리머가 대신 굴릴 수도 있습니다.

시청자 명령

명령동작
!참가 [팀]참가. 팀전이면 팀 이름 지정
!주사위 !굴려주사위 굴리기 (룰렛 모드면 추첨)
!내위치내 위치, 마신 잔, 면제권, 대기 벌칙
!면제권면제권 1개 사용. 키핑 모드면 대기 벌칙 하나 면제
!벌칙 / !완료내 대기 벌칙 보기 / 가장 오래된 것 완료
!지목 닉네임내가 받은 지목샷의 대상 정하기
!순위잔 수 순위 상위 5명
!나가기퇴장

스트리머·매니저 명령

명령동작
!시작 !일시정지 !재개 !종료 [사유]게임 진행 상태
!다음다음 차례로 (방치 시)
!굴려 닉네임특정 말 대신 굴리기 (차례는 안 넘어감)
!완료 닉네임 · !지목 번호 닉네임벌칙 처리
!되돌리기마지막 동작 취소
!주사위설정 1d20주사위 조합 변경 (1개면 더블 규칙 자동 해제)
!프리셋 이름 [보드만]보드 프리셋 적용
!설정 키 값규칙 변경. 예: !설정 penaltyMode queue
!추가 이름 · !강퇴 닉네임 · !초기화게스트 추가 · 퇴장 · 초기화

3. 후원 규칙

위에서부터 첫 번째로 맞는 규칙이 실행됩니다. 정확히 일치·키워드 규칙을 먼저 두고 "이상" 규칙을 마지막에 두세요.

매칭예설명
정확히 (exact)3,000원 → 뒤로 3칸금액이 딱 맞을 때만
키워드 (keyword)"!방패" 포함 → 면제권후원 메시지에 단어가 있을 때. 최소 금액 지정 가능
이상 (min)1,000원 이상 → 주사위, 배수만큼 반복포괄 규칙. 최대 연속 횟수 제한

액션: 굴림, 이동(±칸), 순간이동, 건배(대상 지정), 면제권 선물, 자리 교환, 순서 역방향, 턴 쉬기. 대상은 현재 차례 · 후원자 · 무작위 · 전체 · 지목 중 선택. 1인 하루 한도와 간격, 익명 후원 허용 여부를 따로 정합니다.

4. 벌칙 처리

즉시 집계는 칸에 도착하는 순간 잔 수가 올라갑니다. 키핑(큐)은 벌칙이 대기열에 쌓이고 실제로 마신 뒤 !완료나 관리 페이지 버튼으로 처리해야 집계됩니다. 지목샷은 두 모드 모두 대상이 정해질 때까지 대기열에 남습니다. 면제권은 대기 벌칙 하나를 없앱니다.

5. 서로 켜지지 않는 규칙

조합이유
룰렛 + 땅 소유룰렛에는 위치가 없음
룰렛 + 더블 3연속 무인도 / 완주 종료이동·완주 개념이 없음
자유 모드 + 방치 타이머 / 더블 규칙차례가 없음
주사위 1개 + 더블 규칙더블이 나올 수 없음

이런 조합을 저장하려 하면 설정이 거절되고 이유가 표시됩니다. 프리셋에는 맞는 조합이 들어 있어 그대로 적용하면 충돌이 없습니다.

6. 방송 종료 시

방송이 꺼지면 게임이 자동 일시정지되고 상태가 보관됩니다. 설정한 시간(기본 2시간) 안에 다시 방송하면 이어서 진행되고, 지나면 게임과 참가자 정보가 정리됩니다. 오프라인 술자리처럼 플랫폼 연결 없이 관리 페이지만으로 진행하는 것도 가능합니다.
